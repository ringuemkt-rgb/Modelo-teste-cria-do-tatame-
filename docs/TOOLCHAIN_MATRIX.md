# Toolchain Matrix

## Objetivo

Conectar as ferramentas certas para reduzir risco de produção.

| Etapa | Ferramenta | Saída |
|---|---|---|
| Game design | GDD + Roadmap | escopo claro |
| Dados | JSON + schemas | conteúdo validado |
| Gameplay | Godot ou protótipo web | loop testável |
| Arte | guia visual + prompts | direção consistente |
| Sprites | Pixelorama / LibreSprite | spritesheets |
| IA de lore | Lore Guardian externo | missões e diálogos em JSON |
| QA | checklist + CI | menos quebra |
| Build | Godot export / web | APK, PC e Web |

## Regra de segurança

Nenhuma ferramenta substitui o teste. A garantia real vem de validação, build frequente e escopo pequeno por sprint.
