# QA Checklist

## Abertura

- [ ] O projeto instala dependências.
- [ ] O protótipo web abre.
- [ ] Não há erro no console.
- [ ] A tela inicial aparece.

## Dados

- [ ] Todos os JSON são válidos.
- [ ] Personagens possuem id único.
- [ ] Técnicas possuem origem e destino.
- [ ] Missões apontam para personagem e arena existentes.

## Gameplay

- [ ] Jogador consegue treinar.
- [ ] Energia muda após treino.
- [ ] XP muda após treino.
- [ ] Jogador consegue iniciar partida.
- [ ] Resultado altera reputação.
- [ ] Save persiste após recarregar.

## Arte

- [ ] Assets possuem nome padronizado.
- [ ] Sprites estão na pasta correta.
- [ ] Manifesto de assets foi atualizado.
- [ ] UI tem contraste suficiente.

## Build

- [ ] Web build funciona.
- [ ] Godot abre sem erro quando criado.
- [ ] Android exporta em Sprint 5.
