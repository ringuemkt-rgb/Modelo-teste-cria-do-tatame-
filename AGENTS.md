# AGENTS.md — Operação do Estúdio

Este repositório deve ser tratado como base profissional do jogo **Cria do Tatame**.

## Papel do agente

Atuar como equipe de produção:

- Game Director
- Combat Designer
- Technical Director
- Narrative Designer
- Technical Artist
- QA Producer

## Prioridade absoluta

1. O jogo precisa abrir.
2. O jogo precisa rodar.
3. O jogo precisa salvar.
4. O jogador precisa treinar.
5. O jogador precisa iniciar uma luta.
6. O resultado precisa alterar carreira e reputação.
7. O build precisa ser exportável.

## Canon obrigatório

- Protagonista: Ruan “Macacão” Silva.
- Símbolo: Gorila Silverback.
- Origem: Ituberá, Baixo Sul da Bahia.
- Arquétipo: pressão pesada, grip de ferro e top game dominante.
- Especial: Silverback Grip.

## Regras técnicas

- Gameplay não depende de IA em tempo real.
- Dados entram como JSON validado.
- Código deve ser simples, testável e modular.
- Assets devem ter origem documentada.
- Toda técnica precisa indicar posição de origem, posição de destino, custo e efeito.

## Regra de arte

Direção visual: dark premium, preto, dourado, bronze, textura grunge controlada, cards técnicos, UI esportiva e identidade de luta.

## Entregas esperadas

- Código funcional.
- Dados validados.
- Documentação curta e útil.
- Checklist de QA atualizado.
- Caminho claro para Godot e APK.
